# MITSO Study

Бесплатная платформа для подготовки к сессии студентов МИТСО: экзаменационные вопросы с ответами, конспекты с формулами, карточки с повторением по графику, экзамен-билеты, поиск, избранное и заметки.

Стек: React + TypeScript + Vite, чистый CSS. Статический сайт без сервера: прогресс хранится в браузере (localStorage).

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # проверка контента + типов + сборка в dist/
npm run preview    # посмотреть собранную версию
```

## Что внутри

| Раздел | Что делает |
|---|---|
| Лендинг `/` | Описание, живой пример вопроса, список предметов |
| Предметы `/learn` | Дневная цель, серия занятий, «Продолжить», прогресс по каждому предмету |
| Предмет | Темы по группам, статусы (новое / учу / знаю), фильтр и поиск по предмету |
| Тема | Ответ или конспект, режим «Сначала вспомни», заметка, избранное, соседние темы (← →) |
| Повторение | Карточки по системе Лейтнера: «Снова / Трудно / Хорошо / Легко», интервалы 1, 3, 7, 16, 35 дней. Горячие клавиши: пробел и 1–4 |
| Экзамен | Случайный билет, таймер, свои ответы, эталон и самооценка; результат влияет на повторение |
| Поиск | По названиям и тексту всех предметов, подсветка, история запросов |
| Профиль | Дневная цель, резервная копия прогресса в файл, загрузка копии, сброс |

## Материалы

Все материалы лежат в `content/`, **один файл = один предмет**. Код менять не нужно: положили файл, и предмет появился на сайте. Сейчас там пять предметов, загруженных из присланных файлов.

### Формат (schemaVersion 2)

```json
{
  "schemaVersion": 2,
  "id": "economic-theory",
  "title": "Экономическая теория",
  "description": "Короткое описание",
  "icon": "landmark",
  "course": 1,
  "groups": [{ "id": "market", "title": "Спрос и предложение" }],
  "items": [
    {
      "id": "economic-theory-012",
      "num": 12,
      "title": "Спрос. Закон спроса",
      "group": "market",
      "kind": "qa",
      "body": "**Спрос** — желание и возможность купить…\n\n- пункт\n- пункт",
      "updatedAt": "2026-11-13"
    }
  ]
}
```

- `kind: "qa"` — вопрос и ответ (участвует в карточках и экзамене). `body` — Markdown: заголовки, списки, таблицы, **жирный**, ссылки.
- `kind: "lesson"` — текстовый урок (Markdown, формулы вставлены картинками `![f:34x28](lessons/…png)`). Тему можно отметить прочитанной.
- `kind: "pages"` — урок из страниц PDF-конспекта: список картинок `pages`, для поиска — `search`.
- `id` темы уникален среди **всех** предметов (`a-z 0-9 -`) и не меняется после публикации: на него ссылаются прогресс, избранное и заметки.
- Иконки предмета: `book`, `landmark`, `gavel`, `calculator`, `grid`, `trending-up`, `scale` (список в `src/lib/icons.tsx`).

`npm run validate` (запускается и перед сборкой) находит битый JSON, повторяющиеся id, пустые поля и отсутствующие картинки.

### Импорт из файлов

| Источник | Команда |
|---|---|
| PDF/текст «вопрос — ответ» | `pdftotext -enc UTF-8 файл.pdf файл.txt`, затем `node scripts/import-qa.mjs scripts/specs/economic-theory.json` |
| Учебник в `.docx` (формулы-картинки) | `node scripts/import-docx.mjs scripts/specs/math-analysis.json` (нужен Windows: формулы WMF конвертируются в PNG) |
| PDF-конспект «страницами» | `pip install pymupdf`, затем `python scripts/import-pdf-pages.py scripts/specs/math-practicum.json` |

Спецификация (`scripts/specs/*.json`) описывает исходный файл, предмет и группы вопросов. Скопируйте любую и поправьте под свой файл.

## Настройки

- `src/config/site.ts` — **обратная связь**: укажите `endpoint` (Formspree, Web3Forms) или `email`, без этого форма честно пишет, что не подключена. Также «Часто ищут» в поиске.
- Дневная цель и резервная копия прогресса — в приложении, раздел «Профиль».

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите проект (ветка `main`).
2. **Settings → Pages → Source: GitHub Actions**.
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`, сайт обновляется на `https://<user>.github.io/<repo>/`.

Сайт использует `HashRouter` и относительные пути, поэтому работает по любому адресу, включая будущий свой домен, без настройки.

```

```

## Ограничения

- Прогресс хранится только в браузере. Перенос на другое устройство — через резервную копию в «Профиле»; аккаунты и синхронизация придут вместе с сервером.
- Адреса используют `#` (HashRouter), поэтому поисковики индексируют отдельные темы слабо.
- Конспект «Высшая математика, часть 1» показан страницами исходного PDF: так формулы и таблицы остаются точными, но текст страниц не выделяется и не копируется (поиск по ним работает).
- Рекламные блоки (Яндекс РСЯ) из первоначального ТЗ не подключены.
